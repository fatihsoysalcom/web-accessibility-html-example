# Web Accessibility HTML Example

This example demonstrates fundamental web accessibility principles using a simple HTML page. It showcases semantic HTML, `alt` attributes for images, properly associated form labels, keyboard navigability with visible focus indicators, and ARIA attributes to enhance usability for screen readers and other assistive technologies. The goal is to make web content perceivable, operable, understandable, and robust for all users.

## Language

`html`

## How to Run

Save the code as `index.html`. Open the `index.html` file in any modern web browser. Use the Tab key to navigate through interactive elements and observe the focus indicator.
